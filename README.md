# Multi-Agent-AI-Assistant

Developed a full-stack AI platform where specialized agents collaborate to provide startup founders with market research, competitor analysis, and funding guidance
- Implemented 4 autonomous agents (Research, Analysis, Summary, Report) using LangChain framework, orchestrated through a custom coordination system
- Built RAG (Retrieval Augmented Generation) system using ChromaDB vector database, enabling context-aware responses from uploaded documents
- Integrated web search API for real-time information gathering and automated report generation in PDF/Markdown/HTML formats
- Designed responsive React-based UI with Next.js 14, TypeScript, and Tailwind CSS, featuring real-time agent status tracking
- Technologies: Python, FastAPI, LangChain, OpenAI GPT-4, ChromaDB, Next.js, TypeScript, React, Tailwind CSS
